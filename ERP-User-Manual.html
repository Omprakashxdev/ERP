1. Introduction & Getting Started

🏢 What is SAEC ERP?

SAEC ERP is a comprehensive enterprise resource planning system designed for infrastructure consultancy firms. It manages projects, finances, contracts, vehicles, assets, and daily operations — all in one secure, AI-powered platform.

📊 12+ Modules

Fund Flow, Due Bills, WIP, Contractors, Tenders, Payments, Vehicles, Assets, In-Out Register, TADA Bills, Tasks, Reports

🤖 AI-Powered

AI Executive Summary, AI Chat Assistant for instant answers about your data

📤 Bulk Import

Upload CSV or Excel files to import data in bulk across all modules

🔒 Role-Based Access

Admin, Manager, Staff, and Auditor roles with granular permissions

17. Bulk Import (All Modules)

📤 Upload Data in Bulk

Every module has a "Bulk Import" button in the top-right corner. Use it to upload data for multiple records at once.

How to Use Bulk Import

  1. Go to any module page (e.g., Contractors)
  2. Click the "Bulk Import" button
  3. Download a CSV or Excel template — this shows the correct column headers
  4. Fill in your data in the template (using Excel or Google Sheets)
  5. Save the file as CSV or XLSX
  6. Upload the file using the file picker, or paste CSV data directly
  7. Click "Import" — records will be created in the database
  8. Review success/error messages — fix any errors and re-import
💡 Relation Fields: For fields like "Project" or "Staff", just enter the name (e.g., "GUDM Kutiyana UGD DPR"). The system will automatically look up the correct ID.
⚠️ Important: Make sure related records (Projects, Staff, Clients) exist before importing modules that reference them.
